（路径均含 Astro base：/plumbing/；部署后 = https://你的域名/plumbing/community-widget/...）

--------------------------------------------------------------------------------
一、代码 / 仓库里已经弄好的（你可直接验收）
--------------------------------------------------------------------------------
1. property-value-risk.html  
   独立计算器页；URL 参数：usd、city、benchmark、accent（仅 #RGB/#RRGGBB）。

2. embed.js  
   按 data-* 注入 iframe，指向同目录下的 property-value-risk.html。

3. embed-test.html  
   本地/静态服验收 embed 用（勿用 file://）。

4. index.html  
   小导航页：链到 demo、embed-test、OUTREACH、本说明。

5. OUTREACH-EMAIL.txt  
   英文外联信模板 + iframe + script 嵌入片段（占位符待你填）。

6. package.json 脚本（在 site-plumbing-v2 目录下）  
   - npm run build:plumbing-v2     → 全站构建并把产物收进 dist/plumbing/（含本 widget）  
   - npm run serve:dist            → 本地起静态服看 dist（默认端口见终端）  
   - npm run dev:plumbing-v2       → 开发服；浏览器开 /plumbing/community-widget/embed-test.html  

7. 与站内 ValueProtectionCalculator.astro 的交叉注释（改公式时请两边对齐）。

8. 根目录 _redirects：/ → /plumbing/ 302，与 Hub 子路径一致。

--------------------------------------------------------------------------------
二、我不能替你做、必须由你完成的（物理 / 账号 / 法律边界）
--------------------------------------------------------------------------------
1. 真实身份与联系方式  
   邮件里的姓名、州、邮箱、电话、LinkedIn 等只能你自己填；不能代你「成为」发信人。

2. 生产域名与部署  
   Cloudflare Pages / 其他主机、DNS、SSL、环境变量（如 PUBLIC_SITE_URL）、CI 触发——需你的账号与操作；我无法登录你的控制台。

3. 发信与跟进  
   实际发送邮件、对方回复、谈判措辞、是否上站——只能你做。

4. 法律与合规复核  
   若你代表公司或向居民提供「数据」类内容，是否需免责声明/隐私政策/律师审阅，须你或法务决定；我只能写「教育示意、非估价」级文案，不构成法律意见。

5. 把「示意工具」说成「官方 USGS 计算」  
   不能：当前工具未接 USGS API。若以后接联邦开放数据，需另改文案与实现。

6. 对方 CMS 里的粘贴与权限  
   每个 HOA/论坛后台不同；我不能代你登录对方网站发帖或嵌入。

7. 外链与 SEO 结果  
   Google 是否收录、是否判为优质编辑链接——算法与人工审核不在控制内；只能诚实做资源与关系。

--------------------------------------------------------------------------------
三、推荐你自己的最短操作顺序
--------------------------------------------------------------------------------
1) npm run build:plumbing-v2  
2) npm run serve:dist → 终端会显示端口（默认脚本为 5050）；浏览器打开 http://localhost:5050/plumbing/community-widget/index.html  
3) 部署 dist（或你们流水线规定的产物目录）到线上  
4) 编辑 OUTREACH-EMAIL.txt，把 YOUR-DEPLOYED-DOMAIN 换成 https 真实域名  
5) 一封一封发（或你们合规允许的节奏），记录对方站点与是否同意嵌入
